HEBA 18TH BIRTHDAY WEBSITE
--------------------------
GitHub Pages-ready static website with 8 linked HTML pages.
Included assets:
- assets/heba-photo-1.jpg through heba-photo-5.jpg
- assets/heba-song.mp3

Publish:
1. Extract the ZIP.
2. Upload all files and the assets folder to the root of your GitHub repository.
3. In GitHub: Settings > Pages > Deploy from a branch > main / root.
4. Open the published URL. Music starts only after the visitor presses the music button (browser autoplay policy).
